# maki-meta-ros  
Aplicación nativa de Android (Meta Quest / Android) para publicar datos de teleoperación y recibir parámetros de realimentación háptica.

**maki-meta-ros** es una aplicación Android desarrollada en **Java/Kotlin + NDK** que permite enviar datos de teleoperación basados en los botones de las Touch Plus de un Meta Quest y recibir desde un servidor HTTPS local, intensidades proporcionales de realimentación háptica. 

Este proyecto sirve como base para integrar **Meta Quest** (Quest 2/3/Pro) con cualquier dispositivo Android que pueda conectarse a un servidor local.

---

## ✨ Características

- ⚙️ App nativa Android (Java/Kotlin)  
- 📡 Publica datos de teleoperación a un servidor HTTPS en la red local
- 💡 Pensado para funcionar en **Meta Quest** (APK instalable)  
- 📦 Proyecto listo para Android Studio + Gradle
